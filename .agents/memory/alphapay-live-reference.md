---
name: Référentiel AlphaPay vivant
description: Écarts entre documentation statique, réseaux actifs et routes effectivement disponibles pour le marchand.
---

Consulter les référentiels vivants avant de conclure qu’un pays ou un opérateur AlphaPay est absent, disponible ou limité à une devise donnée.

**Why:** La documentation statique omettait plusieurs réseaux et pays réellement actifs. À l’inverse, certains réseaux marqués actifs n’avaient aucun tarif ni route disponible pour le marchand. Les référentiels de réseaux, de tarifs et de devises peuvent aussi ne pas évoluer ensemble.

**How to apply:** Croiser les réseaux actifs avec les disponibilités marchand pour chaque sens. Une absence de route ou de cotation doit être explicite, pas remplacée par une disponibilité supposée. Un résultat de catalogue ne valide ni les permissions de payout ni un paiement réel.
